# Приложение «Поговорим» для компьютера (Windows)

Подробная инструкция: как собрать, проверить и выпустить отдельную программу
для ПК, которая открывает твой мессенджер в своём окне.

---

## Что это и как работает

- Это **программа-окно**: запускаешь `.exe` — и мессенджер открывается
  в отдельном окне, как обычное приложение (не в браузере).
- Программа **не хранит переписки у себя** — она показывает мессенджер
  с твоего сервера. То есть аккаунты, друзья и чаты — общие с телефоном и сайтом.
- При первом запуске программа **спрашивает адрес сервера** (например,
  `https://твой-домен`) и запоминает его в файле `server.txt` рядом с программой.
- Пока сервер работает — приложение работает. Выключишь сервер — приложение
  не сможет подключиться.

---

## Часть 1. Собрать программу (одна кнопка)

1. Открой папку **`desktop`**.
2. Дважды щёлкни по файлу **`build.bat`**.
3. Подожди 1–2 минуты. Появится окно с сообщениями, в конце — «ГОТОВО!».
4. Готовый файл появится здесь же: **`desktop\Поговорим-для-Windows.exe`**.

`build.bat` сам:
- поставит нужные библиотеки (`pywebview`, `pyinstaller` и другие);
- нарисует иконку из картинки проекта;
- соберёт `.exe` и положит его рядом.

> Если Windows спросит про Python или права — разреши.
> Если появится красный текст — скинь его, помогу.

---

## Часть 2. Проверить

1. Запусти **`Поговорим-для-Windows.exe`** (двойной клик).
2. В окне введи адрес своего мессенджера, например: `https://твой-домен`
3. Нажми ОК — откроется окно с мессенджером.
4. Войди, напиши сообщение — всё должно работать.

---

## Часть 3. Выпустить (опубликовать), чтобы другие скачали

Есть три способа. Выбирай любой.

### Способ A. Просто отправить файл
Самое простое: перешли файл `Поговорим-для-Windows.exe` человеку
(почтой, в мессенджере, на флешке). Он запускает — и всё.
*Минус:* каждому нужно отправлять файл отдельно.

### Способ B. GitHub Releases (рекомендую)
Это специальный раздел для файлов «для скачивания».

1. Открой свой репозиторий на **github.com** (`D1aBet14ek/messenger`).
2. Справа найди раздел **Releases** → **Create a new release**.
3. **Choose a tag** → впиши `v1.0` → **Create new tag**.
4. **Release title:** например `Поговорим 1.0`.
5. Внизу, в разделе **Attach binaries**, перетащи туда файл
   `Поговорим-для-Windows.exe`.
6. Нажми **Publish release**.
7. Готово! Появится страница со скачиванием. Её **ссылку можно давать кому угодно** —
   они скачают программу одним нажатием.

### Способ C. Положить на свой сервер
Если у тебя есть доступ к папке сайта — закинь `.exe` туда и дай ссылку,
например `https://твой-домен/download/Поговорим.exe`.

---

## Часть 4. Обновить программу

Если поменял `desktop_app.py` или иконку:
1. Снова запусти **`build.bat`**.
2. Появится новый `.exe`.
3. Залей его в **Releases** заново (с новым тегом, например `v1.1`).

---

## Часть 5. Приложение на телефон (напоминание)

Отдельный файл телефону не нужен. Открываешь сайт в браузере и устанавливаешь:
- **Android (Chrome):** меню → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран "Домой"».

---

## Важные заметки

- Программа собрана под **Windows 64-bit**. Для macOS её надо собирать на Mac.
- Файл весит ~14 МБ — это нормально (внутрь встроен Python).
- Первый запуск `.exe` может слегка задержаться (Windows проверяет файл) —
  это нормально.
- Адрес сервера хранится в `server.txt` рядом с программой. Если ошибся —
  удали этот файл и запусти заново, спросит снова.
