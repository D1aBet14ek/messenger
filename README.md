# 💬 Поговорим — простой мессенджер

Ты можешь зарегистрироваться, выбрать человека и переписываться с ним.
Все сообщения сохраняются в файл базы данных, поэтому история не пропадает.

---

## Как запустить (самое простое)

1. Открой папку `messenger`.
2. Дважды щёлкни по файлу **`start.bat`**.
   Появится чёрное окно — не закрывай его, пока пользуешься мессенджером.
3. Открой браузер (Chrome, Edge и т.п.) и введи адрес:

   ```
   http://127.0.0.1:5000
   ```

4. Готово! Ты на странице входа. Нажми «Зарегистрироваться» и создай аккаунт.

Чтобы **остановить** программу — просто закрой чёрное окно.

---

## Как проверить переписку (важный трюк)

Тебе нужны **два человека**, чтобы увидеть чат. Сделай так:

1. Зарегистрируй первый аккаунт и войди.
2. Открой **второе** окно браузера **в режиме «Инкогнито»** (или «Приватное окно»)
   и зарегистрируй **второй** аккаунт там.
3. Теперь у тебя две «личности» на одном компьютере. Пиши от одной — вторая увидит
   сообщение через пару секунд (страница обновляется сама).

Обычное окно и окно «Инкогнито» — это как два разных браузера, поэтому входы не мешают друг другу.

## Из чего всё состоит (что за файлы)

| Файл / папка        | Что это                                             |
|---------------------|-----------------------------------------------------|
| `app.py`            | Сам «мозг» программы (на Python)                    |
| `templates/`        | Страницы, которые видны в браузере                  |
| `static/style.css`  | Красота: цвета, кнопки, оформление                  |
| `chat.db`           | База данных — здесь лежат люди и сообщения          |
| `secret_key.txt`    | Личный ключ для входа (создаётся сам)               |
| `start.bat`         | Кнопка «запустить» для Windows                      |
| `requirements.txt`  | Список нужных готовых программ (пока только Flask)  |

> Файлы `chat.db` и `secret_key.txt` появятся сами при первом запуске.

## Что уже работает

- ✅ Регистрация и вход по логину (@имя), как в Telegram
- ✅ **Друзья** — заявка по @логину; видно друг друга только после подтверждения
- ✅ **Счётчики непрочитанных** — красные кружочки с числом у чатов (обновляются сами)
- ✅ **Двухпанельный вид, как в Telegram** — открытый чат слева, список чатов справа;
  ширину панелей можно менять, потянув за границу
- ✅ Чат: отправка сообщений и история
- ✅ Основное работает **без JavaScript** — страницы и формы делает сервер
- ✅ **Плавное самообновление** — сообщения и счётчики обновляются сами, **без мерцания**
  (небольшой скрипт; если JS выключен, всё тоже работает, но без автообновления)
- ✅ **Смайлики** — 20 базовых, добавляются в текст (без JavaScript)
- ✅ **Фон чата** — 18 вариантов (цвета и узоры); выбирается в «Настройках»
- ✅ **Группы** — создание группы; админ может назначать других админов,
  ограничивать запись и добавление людей, убирать участников; выход и удаление группы
- ✅ **Настройки** — имя, описание, аватар, смена пароля и фон чата по умолчанию
- ✅ Пароли хранятся в защищённом виде (не в открытом)

## 📱 Установить как приложение

**На телефон (Android или iPhone):**
1. Открой сайт в браузере (Chrome или Safari).
2. Меню браузера → **«Установить приложение»** (Android)
   или кнопка **«Поделиться» → «На экран "Домой"»** (iPhone).
3. Появится иконка, как у обычного приложения — открывается на весь экран.

**На компьютер (Windows):**
- Готовый файл: **`desktop/Pogovorim.exe`**
- Запусти его → один раз спросит адрес мессенджера → дальше открывается
  отдельным окном, как обычная программа.
- Скачать можно прямо из репозитория на GitHub.

## Если позже захочешь выложить в интернет

Сейчас программа работает только на твоём компьютере (`127.0.0.1`).
Чтобы её увидели другие люди через интернет, программу нужно поставить на «хостинг».

Проект уже подготовлен к этому: настройки (адрес базы, ключ входа, порт) берутся
снаружи, а файл `Procfile` говорит хостингу, как всё запустить.

**Подробная пошаговая инструкция — в отдельном файле [`DEPLOY.md`](DEPLOY.md).**

Коротко о главном выборе:

- **Вариант A (надёжный):** веб-сайт на Render + база PostgreSQL на Neon/Supabase —
  данные точно сохраняются, но нужны регистрации.
- **Вариант B (простой):** PythonAnywhere — проще всего, но бесплатный аккаунт истекает примерно через месяц.
- **Вариант C (платный):** небольшая сумма в месяц — самый беспробный.

Когда решишь — попроси, и я проведу тебя по шагам для выбранного варианта.
